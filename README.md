# 카톡 답장 추천 도우미 (개인용 프로토타입)

카카오톡 채팅방을 열면 접근성 서비스로 최근 대화를 읽어와 Claude API에게
답장 후보 5개를 받아 오버레이 패널로 보여주고, 하나를 고르면 카톡
입력창에 자동으로 채워주는 개인용 안드로이드 앱입니다.

- 답장 후보는 단순 수락/거절이 아니라 **직설적 ↔ 완곡함** 정도를 스펙트럼으로
  나눠서 만들고, 각 후보 카드 위에 색깔 있는 태그(빨강=직설적, 노랑=중간,
  초록=완곡함)로 한눈에 보이게 표시합니다.
- 패널 안의 입력창에 **"이런 느낌으로"** 톤을 직접 적고 적용하면 그 방향에
  맞는 후보 5개를 다시 받아옵니다.
- **"내가 입력창에 쓴 글 다듬기"** 버튼을 누르면 카톡 입력창에 이미 써둔
  내 초안을 읽어와서 의미는 유지한 채 자연스럽게 다듬은 버전을 (역시
  직설-완곡 스펙트럼으로 섞어) 제안합니다.
- **말투/친밀도 학습 (완전히 로컬)**: 채팅방을 읽을 때마다 말풍선을 화면
  좌우 위치로 "내 메시지"와 "상대 메시지"로 구분해서, 내 평소 말투(존댓말
  비율, 문장 길이, 자주 쓰는 이모티콘)와 상대별 친밀도(반말/존댓말 비율,
  이모티콘 빈도)를 기기 안 `SharedPreferences`에 누적 기록합니다. 이 요약은
  매 요청마다 Claude 프롬프트에 짧은 문장으로 포함되어, 이모지 사용 정도와
  문체가 사용자 본인 및 상대와의 관계에 맞게 조절됩니다. 대화 원문 자체를
  저장하지는 않고, 집계된 통계 수치만 남습니다.

## 학습 데이터 관련 주의사항

- 상대방 식별은 채팅방 상단 제목 텍스트를 대충 추정해서 키로 씁니다
  (`ReplyAccessibilityService.getChatPartnerKey()`). 정확하지 않을 수 있고,
  같은 사람이라도 방 제목이 바뀌면 새로운 사람으로 취급될 수 있습니다.
- 데이터는 앱을 지우거나 앱 정보 → 저장공간 → 데이터 삭제를 하면 초기화됩니다.
  별도의 "학습 데이터 초기화" 버튼은 아직 없으니 필요하면 `StyleProfileStore`에
  `clear()` 함수를 추가해서 설정 화면에 연결하는 걸 추천합니다.
- 이 통계는 앱 밖으로 나가지 않지만, 매 답장 요청 시 "요약된 형태로"
  Claude API 프롬프트 안에 포함되어 Anthropic 서버로는 전송됩니다
  (예: "존댓말을 자주 사용함, 메시지를 짧게 씀, 이모티콘을 가끔 씀").
  원문 대화 자체가 아니라 통계 요약이라는 점을 참고하세요.

**전송은 절대 자동으로 하지 않습니다.** 후보를 입력창에 채우기만 하고,
실제로 보내는 것은 항상 사용자가 직접 전송 버튼을 눌러야 합니다.

## 빌드하는 방법

1. [Android Studio](https://developer.android.com/studio) 최신 버전 설치
2. 이 폴더(`kakao-reply-assist/`)를 "Open an existing project"로 열기
3. Gradle sync가 끝날 때까지 대기
4. 실제 기기를 USB로 연결하고 개발자 옵션 → USB 디버깅 켜기
5. `Run ▶` 눌러 기기에 설치

에뮬레이터에서는 카카오톡 자체를 설치하기 까다로우므로, 실제 기기에서
테스트하는 걸 권장합니다.

## 설치 후 설정

1. 앱 실행 → "Claude API 키 입력" 화면에서 [console.anthropic.com](https://console.anthropic.com)에서
   발급받은 API 키 붙여넣기 (기기 Keystore로 암호화 저장됨)
2. "접근성 권한 열기" 버튼 → 설정에서 "답장 추천 도우미" 서비스 켜기
3. "다른 앱 위에 표시" 권한 허용 (오버레이 말풍선을 띄우기 위해 필요)
4. 카카오톡 채팅방을 열면 화면 오른쪽 아래에 작은 플로팅 버튼이 뜨고,
   누르면 답장 후보 3개가 뜹니다.

## 중요한 한계와 주의사항 (꼭 읽어주세요)

- **접근성 서비스 남용 정책**: 구글 플레이는 접근성 서비스를 광범위한
  용도로 쓰는 앱에 매우 엄격합니다. 이 앱을 플레이스토어에 올릴 생각이면
  반드시 [접근성 API 사용 정책](https://support.google.com/googleplay/android-developer/answer/10964491)을
  검토하세요. **사이드로드(직접 설치)해서 개인적으로만 쓰는 용도로 설계되어 있습니다.**
- **카카오톡 UI 변경에 취약**: 카톡이 앱을 업데이트하면서 뷰 구조(resource-id,
  클래스명)를 바꾸면 텍스트 추출 로직(`ReplyAccessibilityService.kt`)이
  깨질 수 있습니다. `dumpsys` 나 Android Studio의 Layout Inspector로
  실제 리소스 ID를 확인하고 맞춰서 고쳐야 할 수 있습니다.
- **개인정보**: 대화 내용이 매 요청마다 Anthropic API로 전송됩니다.
  민감한 대화방에서는 끄고 쓰는 걸 권장하며, 코드 내 `EXCLUDED_ROOMS`
  같은 방 단위 on/off 로직을 추가하는 걸 추천합니다.
- **카카오톡 이용약관**: 자동화 도구로 메시지를 대신 작성/전송하는 행위가
  이용약관에 위배될 수 있는지 반드시 직접 확인하세요. 이 앱은 전송을
  자동화하지 않고 입력창까지만 채우도록 설계했지만, 그래도 최종 판단은
  본인 책임입니다.
- API 키는 절대 코드에 하드코딩하지 말고, `SecurePrefs.kt`처럼
  EncryptedSharedPreferences를 통해서만 저장/조회하세요.

## 파일 구성

```
app/src/main/java/com/example/replyassist/
  ReplyAccessibilityService.kt  # 카톡 화면 읽기 + 입력창에 텍스트 채우기
  SuggestionOverlayService.kt   # 플로팅 버튼 + 답장 후보 오버레이 UI
  ClaudeApiClient.kt            # Anthropic API 호출
  MainActivity.kt               # 설정 화면 (API 키, 권한 안내)
  SecurePrefs.kt                # API 키 암호화 저장
app/src/main/res/xml/accessibility_service_config.xml
app/src/main/AndroidManifest.xml
```
